# FiscorAI — robots.txt
#
# Blog and marketing pages are meant to be found and cited — that's the whole
# point of running a blog. The authenticated app (dashboard, reports, billing,
# etc.) has nothing for a crawler to index anyway since it's behind login, but
# is excluded explicitly rather than left ambiguous.
#
# AI crawlers are split into two families and treated the same way here
# (allowed): "training" bots (GPTBot, ClaudeBot, Google-Extended, CCBot) build
# models from crawled content, "search/retrieval" bots (OAI-SearchBot,
# Claude-User, PerplexityBot) fetch pages live to answer a user's question and
# cite the source. For a content-marketing blog whose goal is reach and
# citation, blocking either category works against the point of publishing —
# flip specific bots to Disallow below if that calculus changes later.

User-agent: *
